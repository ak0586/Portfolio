FLUTTER · GEOSPATIAL02

BhuMitra Mobile app

A Flutter app for measuring land boundaries in the field and sharing clear survey results.

BhuMitra uses GPS walking and map-based boundary capture to calculate plot areas, convert measurement units, save plots, and create shareable PDF reports. A NestJS backend supports accounts and real-time collaborative surveys.

FlutterRiverpodMaps & GPSPDF reports
  • Walk-the-boundary and map drawing modes
  • Saved plots and area-unit conversion
  • Collaborative surveys and report sharing

A modular NestJS API backed by PostgreSQL and Redis. REST endpoints handle application data, while Socket.IO rooms synchronize survey participants and boundary updates in real time.
